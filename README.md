# GPU Team Data Visualization — corrected project

This project is ONLY the four-chart team project from `Group Project.pdf`. It has no unrelated Resume or individually invented charts.

## Upload to GitHub
1. Unzip this archive.
2. Upload all files and folders to the **root** of your existing `Eport` repository. Replace prior `index.qmd`, `_quarto.yml`, `styles.css`, `docs/` files, and outdated project folders as needed.
3. In Settings → Pages choose **Deploy from a branch**, `main`, `/docs`.
4. If your repository is `Eport`, use `https://YOURUSERNAME.github.io/Eport/`.

## Important
- This site shows all four exact team slides, with their own writeups.
- Add each teammate's real portfolio URL before submission; none were provided.
- The source workbook and dataset download link were not included in the upload, so data origin and exact Excel workflow should be verified by the team.
